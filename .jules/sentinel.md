## 2026-09-24 - CBOR Decoder Prototype Pollution Vulnerability\n**Vulnerability:** CBOR maps decoded into plain objects allowing untrusted manifests to set the decoded object's prototype via the '__proto__' key.\n**Learning:** The custom minimal CBOR decoder (lib/cbor.js) used for parsing C2PA claims created objects using '{}'. This meant keys like '__proto__' were interpreted as prototype setters instead of regular keys. Since the parsed manifest object isn't used across privilege boundaries, the immediate security impact was informational/latent rather than active.\n**Prevention:** When creating objects from untrusted dictionaries or deserialized data, always use 'Object.create(null)' to ensure the created object has no prototype and therefore no setter for '__proto__'.
